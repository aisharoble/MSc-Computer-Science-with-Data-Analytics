## About this work

Each project will include a short summary of the task, the tools used, my approach and the results. Where relevant, I will also include instructions for running the code and reflections on what I learned.

The portfolio structure is ready. Assignment files and verified project findings will be added as the individual projects are uploaded.

## Adding an assignment

1. Create a folder within the relevant area using a clear project name.
2. Add the code, notebook, report or screenshots needed to understand the work.
3. Copy the [project summary template](templates/project-summary.md) into that folder as `README.md` and complete it.
4. Include any setup instructions and credit the datasets, libraries and sources used.
5. Add a link to the completed project in the table above.

Only include material permitted for public sharing. Remove personal information, credentials and student identifiers before uploading. For group assignments, describe my own contribution.
